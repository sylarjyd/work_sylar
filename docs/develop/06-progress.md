## 五、已知问题与限制

1. **真实支付未接**：微信/支付宝需商户号、证书、回调域名；当前 mock 渠道仅联调
2. **Windows NSIS 安装包**：构建末步执行未签名安装器被安全策略拦截，先发 portable
3. **桌面/移动未做运行时验收**：本机会话无交互桌面；需在真实电脑点开验证
4. **App Store 4.2**：纯 WebView 套壳可能被拒，需补原生能力或走 TestFlight/企业分发
5. **pnpm dev 在 Windows 偶发**：并发启动争抢 store 锁（`ERR_PNPM_STORE_DIR_OPEN_OPERATION_LOCK`），
   可改为逐包启动或串行脚本
6. 移动端文件下载/分享、扫码、推送需补 Capacitor 插件
