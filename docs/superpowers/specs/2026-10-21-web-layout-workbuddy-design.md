# 客户端 Web 工作台布局改版 · 对标 WorkBuddy · 设计文档

- 日期：2026-10-21
- 状态：已确认
- 参考：<https://www.workbuddy.cn/app>
- 范围：`apps/web` 客户端工作台外壳与工作台页面；运营端 `apps/admin` 不改

## 1. 背景与目标

当前客户端已经有「侧栏 + 主区 + 常驻成果右栏」的结构，但视觉与交互仍偏向卡片堆叠：消息是带边框和阴影的卡片、成果栏常驻占用 304px、顶部有独立的「新会话」按钮。

参考站 WorkBuddy 的工作台采用更轻的结构：

- 浅灰侧栏（约 272px）+ 纯白主区，侧栏无右边框；
- 侧栏顶部有折叠与搜索；导航 + 「最近」会话列表 + 底部用户区；
- 新任务页为居中大标题 + 大输入框 + 下方推荐卡片；
- 会话页为居中文本流，助手消息无卡片；用户消息右对齐浅灰气泡；
- 输入框固定在底部，圆角 24px，黑色圆形发送按钮，下方居中免责声明；
- 右侧内容（引用来源）按需展开，不常驻。

**目标**

- 客户端工作台的结构、间距、层级与参考站一致，视觉保持中性色为主。
- 保留本产品真实可用的功能与导航命名，不新增无后端支撑的控件。
- 成果区从常驻右栏改为按需展开的右侧抽屉。
- 侧栏搜索与折叠为真实可用交互。
- 运营端零影响：所有新样式使用 `wb-` 前缀，不修改运营端依赖的 `.shell` / `.sidebar` 语义。

**非目标**

- 不新增「+」附件、速度/模型选择、办公/开发模式切换、技能指令等无后端能力。
- 不改业务逻辑、API、SSE 契约、数据库。
- 不改运营端布局与样式。
- 不引入 UI 组件库、CSS-in-JS、图标库或外部字体文件。
- 不做会话全文搜索（本期只按标题在已加载列表内过滤）。

## 2. 已确认的关键决策

| 议题 | 决策 | 理由 |
|---|---|---|
| 改造范围 | 完整复刻参考站工作台布局与交互结构 | 用户明确选择 |
| 导航 | 保留现有功能与命名：工作台 / 知识库 / 连接器 / 套餐与用量 / 运营平台 | 不造不存在的「专家·技能」等条目 |
| 成果区 | 改为右侧按需展开抽屉 | 对齐参考站「引用来源」面板 |
| 配色 | 中性色为主，品牌绿仅小面积保留 | 用户明确选择 |
| 无后端控件 | 不画假控件；搜索做成真实会话筛选 | 避免误导 |
| 实现路径 | 就地渐进改造，`wb-` 作用域 | 改动集中、运营端不受影响 |

## 3. 应用外壳与侧栏

### 3.1 尺寸与颜色

- 侧栏宽 272px（≥1100px），960–1100px 为 248px，≤960px 自动收起为 64px 图标栏。
- 侧栏背景 `#f2f2f2`，主区背景 `#ffffff`，两者之间无边框。
- 侧栏内边距 12px，导航项圆角 10px。

### 3.2 顶部品牌区

- 左侧：品牌图标（保留现有薄荷绿渐变方块，尺寸约 30px）+ 名称「AI 办公智能体」。
- 右侧：两个 34px 图标按钮——「收起侧栏」与「搜索」。
- 收起后隐藏文字与品牌名，仅保留图标；按钮 title 提供说明。

### 3.3 搜索

- 点击搜索按钮，在品牌区下方展开输入框（宽度与侧栏一致），自动聚焦。
- 输入即过滤「最近」会话标题，大小写不敏感；无结果时显示「没有匹配的会话」。
- 再次点击搜索按钮或按 `Esc` 关闭搜索并清空关键字。
- 纯前端过滤，不新增接口。

### 3.4 导航

- 「新建任务」作为独立主按钮，位于品牌区下方，白底描边，禁用条件沿用会话执行中状态。
- 其余导航项：工作台、知识库、连接器、套餐与用量；管理员额外显示「运营平台」外链。
- 激活项背景 `#e8e8e8`、文字墨黑；图标在激活时可用品牌绿。

### 3.5 最近会话

- 标题「最近」；列表项显示会话标题（单行省略）与相对时间（如「3 分钟前」「5 天前」）。
- 相对时间基于会话 `createdAt` 计算；超过 7 天显示日期。
- 当前会话高亮同导航激活样式。
- 执行中禁止切换（沿用现有 `sessionDisabled`）。

### 3.6 底部用户区

- 左侧圆形头像（邮箱首字符大写，背景使用浅灰或品牌绿浅色），右侧显示邮箱与角色（管理员 / 成员）。
- 最右为退出登录图标按钮。
- 移除现有独立 `role-chip` 与底部边框线，改为参考站式的单行用户区。

### 3.7 折叠状态

- 折叠状态写入 `localStorage`（键名 `wb.sidebar.collapsed`），刷新后保持。
- 折叠时导航项仅显示图标，通过 `title` 与 `aria-label` 提供名称；「最近」列表隐藏。
- SSR/水合安全：折叠状态在挂载后读取，避免 hydration 不一致。

## 4. 新任务页

### 4.1 结构（自上而下，水平居中）

1. 大标题「AI 办公智能体，我帮你」，字号 `clamp(32px, 4vw, 44px)`，字重 750；「我帮你」使用品牌绿，其余墨黑。
2. 副标题：「把目标交给智能体：它会调研、写文档、做表格、生成演示稿。」
3. 输入框（设计见 §6）。
4. 4 个推荐卡片：整行圆角卡片，左文右箭头；文案沿用现有 `SUGGESTIONS`（写一份周报 / 调研竞品 / 做一张数据表 / 生成演示稿）。
5. 居中免责声明：「内容由 AI 生成，请核实重要信息。」

### 4.2 交互

- 点击推荐卡片把对应 goal 填入输入框（现有行为）。
- 输入框内容非空且未执行时，发送按钮可用。
- 不显示参考站中的模式切换、附件「+」、速度选择。

## 5. 会话页

### 5.1 顶部栏

- 左侧显示当前会话标题（15px，单行省略），无独立背景与底边线。
- 右侧仅保留「成果」抽屉开关图标按钮，带数量角标（0 时不显示角标）。
- 移除「新会话」按钮；新建入口由侧栏「新建任务」承担。

### 5.2 对话流

- 内容列最大宽 904px，水平居中；上下留白与参考站一致（顶部约 24px，底部为输入框让位）。
- **用户消息**：右对齐，最大宽度 78%，浅灰背景 `#f2f2f2`，圆角 16px，内边距 12px 16px；不使用黑底。
- **助手消息/事件**：无边框、无阴影、无白色卡片背景；按事件类型渲染为紧凑行：
  - 思考：紫色小图标 + 「思考」小标签 + 正文；
  - 工具调用：绿色小图标 + 工具名/参数摘要；
  - 工具结果：成功/失败图标 + 结果摘要；
  - 文档产出：文件图标 + 文件名 +「查看成果」入口（打开右侧成果抽屉；下载在抽屉内完成，因为流式事件里还没有落库后的产物 ID）。
- 事件之间间距 10–14px，使用细分隔或留白，不使用卡片描边。
- 流式执行中显示一行轻量指示：「智能体执行中…」+ 14px 旋转指示器。
- 每条助手文本行在 hover 时显示「复制」图标按钮，复制该行文本；复制成功短暂显示「已复制」。
- 不实现点赞/点踩/重新生成（无对应后端能力）。

### 5.3 确认卡片

- 保留现有确认逻辑（允许/拒绝、乐观禁用、失败回滚）。
- 视觉改为浅琥珀背景 + 1px 琥珀描边，圆角 12px；参数区使用浅色代码块。
- 按钮使用现有 `btn` / `btn-primary` 语义，尺寸 `btn-sm`。

### 5.4 底部输入区

- 输入框固定在会话底部，内容滚动区独立。
- 样式与新任务页一致；上方留 12px 渐变遮罩，避免内容与输入框硬切。
- 免责声明居中显示在输入框下方。

## 6. 输入框规格

- 最大宽度 936px；白底；圆角 24px；边框 `1px solid rgba(0, 0, 0, 0.15)`。
- 阴影：`0 16px 32px -8px rgba(0,0,0,.06), 0 2px 4px -4px rgba(0,0,0,.1)`。
- 内边距：顶部 12px，左右 14px，底部 10px。
- 文本区：15px，行高 1.6，最小高度 64px，最大高度 200px；`Enter` 发送，`Shift+Enter` 换行，输入法组合中不发送。
- 底部行：左侧提示「Enter 发送 · Shift + Enter 换行」；右侧 34px 圆形发送按钮。
- 发送按钮：可用时墨黑底白图标；禁用时浅灰底灰图标；执行中禁用。
- 不渲染附件、模式、速度等控件。

## 7. 成果抽屉

### 7.1 触发与状态

- 默认关闭；点击顶部栏成果图标打开，再次点击、点击关闭按钮或按 `Esc` 关闭。
- 有新成果时图标显示数量角标；新成果到达不自动弹开抽屉。
- 抽屉打开状态不持久化。

### 7.2 布局

- 桌面端：宽 360px，右侧悬浮，距视口右边 16px，垂直方向 16px，白底，圆角 16px，阴影 `var(--shadow-2)`，不挤压主内容。
- 顶部：标题「成果」+ 数量文案 + 关闭按钮。
- 内容：成果卡片列表，可滚动。
- 空态：虚线圆角框 + 「任务产出的文档会出现在这里」。

### 7.3 成果卡片

- 类型色块（docx 蓝 / xlsx 绿 / pptx 橙）+ 文件名 + `大小 · v版本 · 时间` + 下载按钮。
- 未落库的乐观条目显示「落库中…」，不提供下载。
- 下载失败时在主区顶部显示现有错误 banner。

### 7.4 移动端与可访问性

- ≤760px：抽屉全宽（左右 12px），带半透明遮罩；点击遮罩关闭。
- 容器 `role="dialog"`、`aria-label="成果"`；移动端加 `aria-modal="true"`。
- 打开时焦点移到关闭按钮；关闭后焦点回到触发按钮。
- 抽屉出现/消失动画 180ms；`prefers-reduced-motion` 下取消动画。

## 8. 视觉 token

新增 `wb-` 作用域变量（不覆盖运营端使用的现有变量）：

```css
.wb-shell {
  --wb-canvas: #ffffff;
  --wb-sidebar: #f2f2f2;
  --wb-ink: rgba(0, 0, 0, 0.9);
  --wb-ink-2: rgba(0, 0, 0, 0.55);
  --wb-ink-3: rgba(0, 0, 0, 0.38);
  --wb-line: rgba(0, 0, 0, 0.1);
  --wb-line-strong: rgba(0, 0, 0, 0.15);
  --wb-hover: #ebebeb;
  --wb-active: #e8e8e8;
}
```

- 主文本 `rgba(0,0,0,.9)`，次要文本 `rgba(0,0,0,.55)`，占位 `rgba(0,0,0,.38)`。
- 品牌绿沿用 `--mint` / `--mint-strong`，仅用于：品牌图标、标题强调词、激活导航图标、焦点环、头像底色。
- 发送按钮、主按钮使用墨黑（`#1a1a1a`），不再使用绿色。
- 字体栈在现有 `--font` 前插入 `Inter`：`Inter, -apple-system, ...`；不下载字体文件，系统无 Inter 时自然回落。
- 圆角：输入框 24px、卡片 12px、抽屉 16px、气泡 16px、按钮 10px。
- 分隔线统一 `rgba(0,0,0,.1)`，不再使用现有绿色调边框。

## 9. 响应式

| 断点 | 侧栏 | 主区 | 成果抽屉 |
|---|---|---|---|
| ≥1100px | 272px，可折叠 | 904px 内容列居中 | 360px 悬浮 |
| 960–1100px | 248px | 内容列自适应，左右 24px | 360px 悬浮 |
| ≤960px | 64px 图标栏（自动） | 全宽 | 360px 悬浮 |
| ≤760px | 顶部横向栏（沿用现有移动布局） | 全宽，左右 16px | 全宽 + 遮罩 |

- ≤760px 时隐藏搜索框与最近列表，保留新建任务与导航图标。
- 自动收起状态在用户手动展开后不覆盖用户选择：手动折叠状态优先。

## 11. 测试与验收

**自动化**

- `pnpm --filter @ai-office/web test` 通过。
- 为 `relativeTime` 增加单元测试：刚刚 / 分钟 / 小时 / 天 / 超 7 天回退日期。
- 现有 `render-step`、`sse-parser` 等测试保持通过。

**手工验收（Playwright 截图对照）**

1. 新任务页：侧栏 272px 灰底、主区白底；大标题与 4 个推荐卡片；输入框 936px 圆角 24px；黑色发送按钮；底部免责声明。
2. 会话页：用户消息右对齐浅灰气泡；助手消息无卡片；顶部仅标题与成果开关；输入框固定底部。
3. 成果抽屉：点击开关滑出；空态与有文件两种状态；下载可用；Esc 关闭；角标数量正确。
4. 侧栏：搜索能实时过滤会话；折叠后仅图标且刷新保持；底部用户区显示邮箱与角色。
5. 响应式：1920 / 1280 / 1024 / 760 宽度下无横向滚动、无重叠。
6. 运营端 `http://localhost:3001` 的侧栏与表格样式与改版前一致。
7. 执行一次真实任务，确认思考/工具调用/确认卡片/成果下载链路不受影响。

## 12. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 共用 `globals.css` 影响运营端 | 新样式全部加 `wb-` 前缀；验收第 6 项专测运营端 |
| 折叠/搜索引入水合不一致 | 折叠状态挂载后读取；搜索为纯本地状态 |
| 抽屉覆盖内容导致操作受阻 | 桌面端悬浮不挤压；Esc 与关闭按钮；移动端遮罩可点 |
| 移除「新会话」按钮改变习惯 | 侧栏「新建任务」保持等价功能与禁用逻辑 |
| 视觉改动导致对比度不足 | 正文 `rgba(0,0,0,.9)`、次要 `rgba(0,0,0,.55)`，不使用低于 `.38` 的文字 |
