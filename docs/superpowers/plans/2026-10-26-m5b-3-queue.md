# M5b-3 任务队列实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将运行入口改为 BullMQ 队列驱动，交付排队、取消/重试、断点续跑与可观测能力。

**Architecture:** `POST /api/sessions/:id/tasks` 预检后落 `Task/Run(queued)` 并入队，worker 出队后才预占积分并调用 runtime；事件先落 `Step` 再经 Redis 发布，HTTP 侧先订阅再回放 DB，实现断线续流。每轮结束 runtime 发 `checkpoint` 事件，BFF 落 `RunCheckpoint`，续跑从最后完整轮继续。

**Tech Stack:** NestJS/Fastify、Prisma/Postgres、BullMQ + ioredis、Node 20、Next.js 15、Ant Design 5、Vitest。

**约定：** 直接在 master 开发（不使用分支/worktree）；每步结束提交，提交信息用中文；`apps/bff/prisma/comments.sql` 不纳入提交。

/** 入队前只读准入：套餐有效、RPM 未超、余额>0、价格齐全；不写库、不预占。 */
async admitRun(tenantId: string): Promise<void> {
  const { plan, sub } = await this.ensureSubscription(tenantId);
  if (sub.status !== 'active' || sub.periodEnd.getTime() <= Date.now()) {
    throw new PlanExpiredError();
  }
  const rl = await this.limiter.hit(`run:${tenantId}`, plan.rpm);
  if (!rl.allowed) {
    this.metrics?.rateLimitHits.inc({ scope: 'tenant' });
    throw new RateLimitedError(rl.retryAfter);
  }
  const credit = await this.prisma.tenantCredit.findUnique({ where: { tenantId } });
  const available = (credit?.balance ?? 0) - (credit?.reserved ?? 0);
  if (available < 1) throw new InsufficientCreditsError();
  const prices = await this.loadPrices(this.prisma);
  for (const model of plan.allowedModels) {
    if (!prices[model]) throw new Error(`model_price_missing:${model}`);
  }
}
```

// run-event-bus.ts
export interface RunEventBus {
  publish(runId: string, msg: SseMessage): Promise<void>;
  subscribe(runId: string, handler: (msg: SseMessage) => void): Promise<() => void>;
}

export class LocalRunEventBus implements RunEventBus { /* EventEmitter，按 runId 维护 handler 集合 */ }

export class RedisRunEventBus implements RunEventBus {
  constructor(private readonly publisher: Redis, private readonly subscriberFactory: () => Redis) {}
  async publish(runId, msg) {
    await this.publisher.publish(channel(runId), JSON.stringify({ event: msg.event, data: msg.data }));
  }
  async subscribe(runId, handler) {
    const sub = this.subscriberFactory();           // 每次挂接独立连接
    await sub.subscribe(channel(runId));
    sub.on('message', (_ch, raw) => { try { handler(JSON.parse(raw)); } catch { /* 忽略坏帧 */ } });
    return async () => { await sub.unsubscribe(channel(runId)).catch(() => undefined); sub.disconnect(); };
  }
}
const channel = (runId: string) => `run:${runId}:events`;
```

```ts
export interface RunJob {
  runId: string; taskId: string; sessionId: string; tenantId: string; userId: string;
}

@Injectable()
export class RunQueueService {
  constructor(
    private readonly config: QueueRuntimeConfig,
    @Optional() @Inject(RUN_QUEUE) private readonly queue: Queue | null,
    private readonly executor: RunExecutorService,
    private readonly tasks: TasksService,
    private readonly settings: SettingsService,
    private readonly events: RunEventBus,
    @Inject(BFF_METRICS) private readonly metrics: BffMetrics,
  ) {}

  /** 队列关闭或 Redis 不可用时同步（异步发起）执行，不阻塞调用方。 */
  async submit(job: RunJob): Promise<'queued' | 'inline'> {
    if (!this.config.enabled || !this.queue) {
      void this.executor.execute(job).catch((err) => {
        this.logger.error(`run ${job.runId} 内联执行失败: ${(err as Error).message}`);
      });
      return 'inline';
    }
    await this.enqueue(job);
    return 'queued';
  }

  async enqueue(job: RunJob): Promise<void> {
    const cfg = await this.settings.getQueueConfig();
    const queued = await this.tasks.countQueued(job.tenantId);
    if (queued >= cfg.maxPerTenant) throw new QueueFullError();
    await this.queue!.add('run', job, {
      jobId: job.runId,
      removeOnComplete: 1000,
      removeOnFail: 5000,
    });
    this.metrics.runsEnqueued.inc();
    this.metrics.runQueueDepth.inc();
  }

  async remove(runId: string): Promise<boolean> {
    const job = await this.queue?.getJob(runId);
    if (!job) return true;
    await job.remove().catch(() => undefined);
    return (await this.queue!.getJob(runId)) === undefined;
  }
}
```

```ts
@Injectable()
export class RunRelayService {
  async attach(runId: string, reply: FastifyReply, opts: { afterSeq?: number } = {}): Promise<void> {
    const run = await this.tasks.findRun(runId);          // status, lastError...
    reply.hijack();
    writeHead(reply, 200, SSE_HEADERS);
    const buffer: SseMessage[] = [];
    let live = false;
    const off = await this.events.subscribe(runId, (m) => {
      if (!live) buffer.push(m);
      else this.write(reply, m);
    });
    const steps = await this.tasks.listSteps(runId, opts.afterSeq ?? -1);
    let lastSeq = opts.afterSeq ?? -1;
    for (const s of steps) { lastSeq = Math.max(lastSeq, s.seq); this.write(reply, { event: 'step', data: s }); }
    live = true;
    for (const m of buffer) {
      if (m.event === 'step' && (m.data as AgentEvent).seq <= lastSeq) continue;
      if (m.event === 'step') lastSeq = (m.data as AgentEvent).seq;
      this.write(reply, m);
    }
    if (isTerminal(run.status)) {
      this.write(reply, terminalMessage(run));
      off(); reply.raw.end();
      return;
    }
    this.write(reply, { event: 'status', data: { runId, status: run.status } });
    const heartbeat = setInterval(() => reply.raw.write(': ping\n\n'), 15_000);
    const close = () => { clearInterval(heartbeat); off(); };
    reply.raw.on('close', close);
    // 终态由 worker 发布 done/error；本挂接不主动轮询。
  }
}
```

- `GET /api/runs/:id/stream`：JWT + `tasks.assertRunOwned` → `relay.attach`；
  `afterSeq` 取 `Last-Event-ID` 头或 query，非法值按 -1。
- 终态消息：`done` → `{event:'done',data:{runId}}`；`failed` → `{event:'error',data:{message:lastError||'run_failed'}}`；
  `canceled` → `{event:'status',data:{runId,status:'canceled'}}` + `done`。
- `checkpoint` 事件在 `write` 中统一过滤。

  const run = await this.tasks.findOwnedRun(runId, tenantId, userId);

async retry(runId: string, tenantId: string, userId: string): Promise<RetryRunResultDto> {
  const run = await this.tasks.findOwnedRun(runId, tenantId, userId);
  if (run.status !== 'failed' && run.status !== 'canceled') throw new ConflictException('run_not_retryable');
  const task = await this.prisma.task.findUnique({ where: { id: run.taskId } });
  if (!task?.input) throw new ConflictException('task_snapshot_missing');
  const claim = await this.prisma.task.updateMany({
    where: { id: task.id, attempts: task.attempts },
    data: { attempts: { increment: 1 }, status: 'queued', lastError: null, startedAt: null, endedAt: null },
  });
  if (claim.count !== 1) throw new ConflictException('task_busy');
  const next = await this.prisma.run.create({
    data: { taskId: task.id, attempt: task.attempts + 1, status: 'queued', traceId: currentTrace()?.traceId ?? null },
  });
  await this.queue.submit({ runId: next.id, taskId: task.id, sessionId: task.sessionId, tenantId, userId });
  this.metrics.runsRetried.inc();
  return { runId: next.id, taskId: task.id, attempt: next.attempt };
}
